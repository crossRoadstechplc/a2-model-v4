A2 E Fleet Operations Financial Model - Replication Reference Guide
=====================================================================

Purpose
-------
This file is the implementation guide for rebuilding the workbook
`A2 E FLEET OPERATIONS  FINANCIALS-VER 1 c.xlsx` so that:
1. loading the current Excel assumption values reproduces the current Excel outputs exactly, and
2. changing assumptions recalculates all dependent results recursively.

Source files
------------
- Workbook: A2 E FLEET OPERATIONS  FINANCIALS-VER 1 c.xlsx
- Companion reference: A2_Fleet_Financial_Model_Reference.md
- Machine-readable build spec: A2_Fleet_Model_Replication_Reference.json

Core modeling principle
-----------------------
Treat the Excel workbook as the source of truth for exact formulas, sheet names,
row positions, and output values.
Do NOT normalize or "improve" formulas during the first replication pass.
Replicate literal workbook behavior first, including quirks.

Workbook flow
-------------
ASSUMPTIONS_DATA
  -> REVENUE PROJECTION
  -> CAPEX & DEPRECIATION
  -> SOURCE_USE OF FUNDS
  -> INCOME STATEMENT 
  -> CASH FLOW
  -> BALANCE SHEET
  -> VALUATION SUMMARY
  -> KEY METRICS

Sheet roles
-----------
- ASSUMPTIONS_DATA: master driver sheet
- CAPEX & DEPRECIATION: capex schedule, depreciation grid, asset values
- SOURCE_USE OF FUNDS: equity subscription, cumulative equity, use of funds
- REVENUE PROJECTION: tonnes, rate, revenue pass-through
- INCOME STATEMENT : revenue, cost, opex, EBITDA, tax, net income, investor returns
- CASH FLOW: operating, investing, financing, closing cash
- BALANCE SHEET: cash, PP&E, equity, retained earnings plug
- VALUATION SUMMARY: EBITDA multiple valuation and investor value
- KEY METRICS: EBITDA margin, net margin, ROE

Critical quirks to preserve
---------------------------
1. The sheet name `INCOME STATEMENT ` has a trailing space.
2. The model uses many direct cell links. Row and column positions matter.
3. Some formulas do not exactly match the apparent label logic:
   - INCOME STATEMENT!C8 = C3*C7
   - INCOME STATEMENT!N12 breaks the usual tax pattern
   - SOURCE_USE OF FUNDS row 5 says "(25%)" but directly links total investment
4. BALANCE SHEET retained earnings is a plug:
   retained earnings = total assets - equity
5. ASSUMPTIONS_DATA row 35 contains an unlabeled formula. Keep only if full parity is required.

Assumption system
-----------------
The assumptions sheet is both:
- the user input layer, and
- an internal calculation layer.

This means assumptions must cascade with each other before they cascade to other sheets.

Important internal assumption cascades
--------------------------------------
1. Fleet additions cascade:
   truck additions -> trucks in operation

2. Fleet scale cascade:
   trucks in operation -> fleet km -> energy purchased -> energy cost

3. Revenue cascade:
   trucks in operation -> fleet trips -> chargeable tonnes
   freight rate ETB -> freight rate USD
   chargeable tonnes x USD rate -> total freight revenue

4. Capex cascade:
   unit truck cost + annual truck additions -> total truck capex
   truck/software/hardware/reserve/contingency -> total investment

Primary hardcoded base assumptions
----------------------------------
Key hardcoded inputs include:
- D3:J3  Number of trucks added each year
- C4     Swaps per truck per day
- C6     Battery packs charged per charger per day
- C8     Cost per truck
- C10:D10  Fleet management software
- C11:D11  Hardware and office equipment
- C12    Operating reserve
- C13:D13 Contingency reserve
- C17    Average km per truck per year
- C19    Energy used per km
- D21:N21 Energy cost per kW
- C24    Number of days per trip
- C29    Average chargeable tonnes per trip
- C31    Base freight rate per tonne in ETB

Important derived assumption blocks
-----------------------------------
- C3 = total trucks added over build period
- D16:N16 = trucks in operation
- D18:N18 = total fleet km
- D20:N20 = total energy purchased
- D22:N22 = total energy cost
- C25 = operating days in year
- C26 = trips per truck per year
- D27:N27 = fleet trips per year
- D30:N30 = chargeable tonnes of fleet per year
- C32:N32 = freight rate per tonne in USD
- D33:N33 = total freight revenue
- D14:N14 = total investment

Cross-sheet cascade
-------------------
1. ASSUMPTIONS_DATA -> REVENUE PROJECTION
   - tonnes, USD rate, revenue

2. ASSUMPTIONS_DATA -> CAPEX & DEPRECIATION
   - truck cost, software, hardware annual capex

3. ASSUMPTIONS_DATA -> SOURCE_USE OF FUNDS
   - total investment, reserve lines

4. ASSUMPTIONS_DATA + REVENUE PROJECTION + CAPEX & DEPRECIATION -> INCOME STATEMENT 
   - revenue
   - energy cost
   - depreciation
   - opex growth / variable opex
   - tax
   - net income

5. INCOME STATEMENT + CAPEX & DEPRECIATION + SOURCE_USE OF FUNDS -> CASH FLOW
   - net income
   - depreciation add-back
   - capex outflow
   - equity injection
   - dividend and dividend tax
   - closing cash

6. CASH FLOW + CAPEX & DEPRECIATION + SOURCE_USE OF FUNDS -> BALANCE SHEET
   - cash
   - PP&E
   - equity
   - retained earnings plug

7. INCOME STATEMENT + SOURCE_USE OF FUNDS -> VALUATION SUMMARY / KEY METRICS
   - EBITDA
   - investor stake value
   - MOIC
   - IRR
   - EBITDA margin
   - net margin
   - ROE

Replication requirements
------------------------
To pass replication:
1. load all base assumption values exactly as in Excel
2. preserve sheet names exactly
3. preserve formula text exactly
4. preserve blank cells where Excel leaves them blank
5. recalculate recursively when any assumption changes
6. validate outputs against the Excel base case
